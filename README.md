The last text message a phone sends at one percent battery, in the voice of the dying phone itself:

> 1%. going dark. tell the charger it was never the cable, it was the distance. tell the apps i never liked them anyway. xoxo, your phone

## Run

```bash
python3 main.py
```

Writes `entry.txt` (one line, 135 characters, plus a trailing newline) to `$ENTRY_OUTPUT_DIR` (default `/output`).
